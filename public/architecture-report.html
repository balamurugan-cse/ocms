1. Executive Summary & Problem Formulation

The DMI Online Complaint Management System (OCMS) provides a unified, transparent, and auditable digital grievance redressal mechanism for DMI College of Engineering. Designed in strict compliance with AICTE grievance redressal regulations and Anna University guidelines, the system replaces manual complaint handling with automated ticket issuance, department routing, SLA countdown monitoring, leadership escalation, and evidence-verified resolution.

2. 3-Tier Layered Architecture

The system is architected in three distinct tiers separating presentation, business logic execution, and data persistence:

Tier Layer Name Technology Stack Functional Responsibilities
Tier 1 Presentation Layer React 19, TypeScript, Tailwind CSS, Vite Responsive user interfaces, role-specific dashboards, public ticket tracking, grievance submission forms, interactive timelines.
Tier 2 Application & Logic Layer Node.js, Express, JWT, FSM Engine Authentication verification, state machine validation, SLA countdown watcher, automated escalation triggers, email dispatching.
Tier 3 Data Persistence Layer JSON Store / Relational Schema, Multer Vault Atomically locked user records, grievance entries, append-only immutable audit logs, photographic and PDF evidence attachments.
